## Weekly homework upload

Upload homework every week in this structure:

```text
homework/
  week-01/
  week-02/
  week-03/
  ...
```

- Create one folder per week using the format `week-XX`.
- Put all files for that week inside the matching folder.
- Commit and push updates every week after finishing the homework.
